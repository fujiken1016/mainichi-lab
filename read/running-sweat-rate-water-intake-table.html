マラソンの水分補給は1時間に何ml？体重差から発汗量を出し、2%以内の飲む量を計算した

2026年11月25日 ／ フジケン

マラソンの水分補給は「喉が渇く前に飲め」と「飲みすぎは危険」の両方を聞きます。1時間に何ml飲めばいいのか、自分の数字がないと決められません。

この記事では、走る前後の体重差から発汗量を出す式と、体重の2%以内で収めるときの飲む量の範囲を、表にしました。

1. 先に結論：発汗量＝（体重の減り＋飲んだ量）÷時間。体重60kg・4時間なら、不足は1時間300mlまで

ACSMの2007年の声明は、運動中に飲む目標を「体重の2%を超える脱水を防ぐこと」とし、個人の発汗量は運動前後の体重から推定できる、と書いています。（PubMed 17277604）

  • 1時間の発汗量（L）＝（走る前の体重−走った後の体重＋飲んだ量）÷走った時間（時間）。体重1kgの減りは、水1Lとして扱います（表1は1時間走った場合）
  • 体重60kgの2%は1.2kg。完走4時間なら、1時間あたり300mlの不足までです（表2）
  • 発汗が毎時800mlなら、飲む量は500〜640mlが範囲です（下限は2%以内、上限は発汗の80%。表3。※筆者の計算）。喉が渇いていなければ、下限まで飲む必要はありません
  • 給水所で1回150ml飲んでも、5kmごとだと毎時254〜360mlにしかなりません（表4。※筆者の計算）

2. ほかのページは何を載せているか

僕が開いた2ページは、発汗量の式か、1回の給水量の目安までで、完走時間と体重から飲む量の範囲を出した表はありませんでした。（2026年11月25日に確認。）

Number Doの記事（日本体育協会の伊藤静夫さんの解説）は、練習前後の体重差から発汗量を出す式と、「脱水率＝体重の減り÷走る前の体重×100」を書いています。給水所での1回の量は、体重が重い人・暑い日はカップ半分以上（100〜150ml）、軽い人・涼しい日は半分以下（50〜100ml）が目安で、あとは喉の渇きで調整するとしています。厳密に発汗量と同じ量を補給する必要はなく、走る前より体重が増えたら飲みすぎ、とも書いています。

rundidaの水分補給計算機は、体重70kg・中強度で毎時0.8Lを出発点に、走行中は発汗量の70〜80%（毎時400〜800ml）を目標にします。係数は公開されていません。ACSM（2007）など3件を参考文献に挙げています。

そこでこの記事は、自分で測った発汗量を入れる形にしました。体重2%を上限にした「飲む量の範囲」と、給水所で飲める量の計算を足しています。

3. 研究の要旨が示していること

2007年のACSMの声明は、運動中に飲む目標を、2%超の脱水と、電解質の大きな変化を防ぐこと、としています。要旨の内容は次のとおりです（PubMed 17277604）。

  • 汗の量と、汗に含まれる電解質の量は、人によって大きく違うので、個別の補給計画が勧められる
  • 個人の発汗量は、運動前後の体重を測って推定できる
  • 運動中は、電解質と炭水化物を含む飲み物が、水だけより有利なことがある

マラソンについては、2007年の総説が、大量の発汗で、成績を落とす水準の脱水が起こりうるとし、「2%超の脱水」と「体重の増加」の両方を防ぐように、補給を個人に合わせることを勧めています（PubMed 17465606）。体重の増加は、飲みすぎのサインです。

どちらの要旨にも、1時間に何mlという数字はありません。数字を決めるのは、自分で測る発汗量です。

4. 発汗量の出し方：体重の減り＋飲んだ量

走る前後の体重差が0.6kgで、0.3L飲んだなら、1時間の発汗量は0.9Lです。表1は、体重差と飲んだ量ごとの値です。

表1：走る前後の体重差と飲んだ量から出す、1時間の発汗量（L。走った時間が1時間のとき。※筆者の計算）
体重の減り飲まなかった0.3L飲んだ0.5L飲んだ
0.3kg減0.3L/時0.6L/時0.8L/時
0.6kg減0.6L/時0.9L/時1.1L/時
0.9kg減0.9L/時1.2L/時1.4L/時
1.2kg減1.2L/時1.5L/時1.7L/時
  1. 走る前に、排尿後の体重を測る
  2. 走る。飲んだ量を、メモしておく
  3. 走った後、汗を拭いてから体重を測る
  4. 体重の減りと飲んだ量を足し、走った時間（時間）で割る

1時間でない練習なら、合計を走った時間（時間）で割ってください。途中でトイレに行ったときは、別の日にやり直します。ペースと気温は、レース当日に近い日を選ぶと、値が使いやすくなります。

5. 体重の2%は、1時間あたり何mlか

体重60kgの2%は1,200mlで、完走4時間なら1時間あたり300mlです。表2は、体重50〜80kgと完走3〜5時間の値です。

6. 飲む量の範囲：発汗から許容を引いた量〜発汗の80%

体重60kg・完走4時間で発汗が毎時800mlなら、飲む量は毎時500〜640mlです。下限は「発汗−許容の300ml」、上限は「発汗の80%（かつ毎時800ml以下）」です。上限は、rundidaの水分補給計算機が書く「発汗量の70〜80%を目標に、毎時800mlまで、100%補充しようとしない」を使いました。Number Doの記事も、発汗量と同じ量を飲む必要はなく、喉の渇きで調整するとしています。

表3：体重60kg・完走4時間のとき、2%以内で収める飲む量の範囲（ml/時。上限＝発汗の80%かつ800ml以下。※筆者の計算）
発汗量飲む量の下限（発汗−許容300）飲む量の上限（発汗の80%、最大800）判定
400ml/時100ml/時320ml/時範囲あり
600ml/時300ml/時480ml/時範囲あり
800ml/時500ml/時640ml/時範囲あり
1000ml/時700ml/時800ml/時範囲あり
1200ml/時900ml/時800ml/時下限が上限を超える。飲む量だけで2%以内に収めるのは難しい

発汗が毎時300ml以下の人は、下限が0になり、水分をとらなくても2%に届きません。それでも渇きを感じたら飲んで構いません。発汗が毎時1,200mlの人は、下限（900ml）が上限（800ml）を超えます。この場合は、飲む量だけで2%以内に収めるのは難しく、ペース配分や暑さ対策を考えることになります。

反対に、喉が渇いていないのに、表の下限まで飲まないでください。飲みすぎると、血液のナトリウムが薄まる低ナトリウム血症（運動関連性）の危険があるとされています。吐き気、頭痛、指のむくみ、お腹がちゃぷちゃぷする感じが出たら、飲むのをやめて、大会の係員に伝えてください。ACSMの2%は「超えない目安」で、目標にして飲み込む量ではありません。

この計算は、体内で作られる水や、グリコーゲンに結びついた水を入れていません。2007年の総説は、これらを「議論のある点」として扱い、補給量への影響は小さいとしています（要旨）。

Number Doの記事は、1回の目安を100〜150mlとし、あとは喉の渇きで調整するとしています。給水所だけで届かなくても、渇きに合わせて飲めば足りる人もいます。表3と表4は計画を立てるときの目安で、本番は体の感覚を優先してください。これは僕の整理です。

8. 使い方と、気をつけること

  1. 本番に近い条件で、1時間走り、表1で発汗量を出します
  2. 体重と完走時間から、表2で許容量を、表3で飲む量の範囲を決めます
  3. 給水所の位置を大会要項で確かめ、表4で、給水所だけでどこまで届くか見ます
  4. 走り終わった後に体重が増えていたら、飲みすぎです。次回は量を減らします

ジェルの量はジェルの本数の表、前日までの食事はカーボローディングの量の表、ペースはサブ4・サブ4.5・サブ5のペース表で決められます。全体の流れは本番までの数字カレンダーにまとめました。

この記事は医療の助言ではありません。持病や心臓・腎臓の病気がある人、走って体調を崩したことがある人は、医師に相談してください。

まとめ

水分補給は、数字を決める前に、自分の発汗量を一度測ることが先です。この記事の要点は次の4つです。

  • 発汗量＝（体重の減り＋飲んだ量）÷時間。ACSMは2%超の脱水を防ぐこと、個別の補給計画を勧める（PubMed 17277604）
  • 体重60kg・4時間なら、不足は毎時300mlまで。発汗800mlなら、飲む量は500〜640ml（上限は発汗の80%。※筆者の計算）
  • 5kmごとの給水所で1回150mlだと、毎時254〜360ml。範囲に届くか、先に確かめる
  • 走った後に体重が増えるのは、飲みすぎのサイン（Number Do）。総説も体重の増加を防ぐよう勧める（PubMed 17465606）
