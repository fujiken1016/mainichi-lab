ブログの挿絵を無料で作れるAI画像生成、10手段を同じお題で試した（実測）

2026年11月6日 ／ フジケン

このサイトの読みものには、記事ごとに挿絵を2枚以上入れています。毎日のように記事を書くと、画像も毎日要ります。有料の画像生成サービスを契約せずにどこまで回せるのかを知りたくて、2026年10月17日に、無料で使えそうなAI画像生成の手段を10通り、同じお題で一度に試しました。

先に結論です。10手段のうち、その日に画像が出たのは5手段でした。APIで使う方法は、無料枠が0か残高が0で4手段とも出ませんでした。いちばん使いやすかったのは、手元のPCで動かす方法（約32秒で1枚・回数の上限なし・0円）です。その後、記事用に作った29枚のうち、使えたのは19枚でした。

1. 比較記事を3本開いて、足りなかったもの

書く前に、「AI画像生成 無料 比較」で上位に出てくる記事を3本、本文まで開いて読みました（2026年11月2日）。

参考になった点は3つあります。1本目は、冒頭で「無料のままで足りる人・足りない人」を先に分けていて、読む前に自分がどちらか分かる作りでした。2本目は、2つのアプリに同じお題を出して、出てきた画像を並べていました。3本目は、サービスごとに無料枠・商用利用・透かしの有無を表にしていました。この「冒頭で結論」「同じお題で並べる」「条件を表にする」の3つは、この記事でもそのまま使っています。

一方で、試した回数はどの記事も1サービス1回程度で、比べた手段も2〜3個でした。また、「APIで使う場合」と「手元のPCで動かす場合」を、Web版と同じ表に並べたものは見つけられませんでした。ここを、同じ日に10手段を試した記録と、その後に記事用で作った枚数で埋めます。

2. 試し方：同じお題・同じ日・同じPC

条件は次のように揃えました。

  • お題は全手段で同じ「和室の勉強机に、ノートPCと湯のみ。フラットなベクター調、パステルカラー、文字なし」
  • 試したのは2026年10月17日の1日だけ。Web版は、自分のアカウントでログインした無料プランで試しました
  • 手元で動かす方法は、メモリ24GBのMacで実行しました
  • かかった時間は、お題を送ってから画像が出るまでの実測です。各手段1〜数枚なので、時間は目安として読んでください

無料枠の正確な上限は、ほとんどの手段で公表されていないか、確かめきれていません。表では「この日に何枚出たか」だけを書いています。

意外だったのは、APIの残高が0でも、同じ会社の無料Web版では画像が出たことです。ChatGPTはAPIが使えない状態でも、無料のWeb版では1枚出ました。「APIが使えないから画像は作れない」と判断するのは早すぎました。

ただし、Web版は人が画面で操作する前提のサービスです。プログラムから自動で操作すると、規約に触れたり、アカウントを止められたりするおそれがあります。実際、同じ日に、ログインした別の生成サービスを自動操作していたアカウントが2つ止められました。なので、毎日たくさん作る用途にはWeb版を使わず、手元のPCで動かす方法を中心にしています。

商用利用の条件も、手段ごとに確かめた範囲が違います。Hugging Faceの2つのモデルは、モデルの説明ページでApache-2.0と確認しました。手元で使ったJuggernaut-XLは、配布ページでCreativeML OpenRAIL-M（出力の利用は可能で、使い方の制限条項がある）と確認しましたが、規約の全文までは読めていません。ChatGPTとGeminiのWeb版、Pollinationsは、この日に規約ページを取得できなかったか確認していないので、ここでは「要確認」とします。

4. 同じお題で出た4枚を並べて見る

実際に出た画像のうち、商用利用の条件を確認できた4枚を並べます。お題は全部「和室の勉強机に、ノートPCと湯のみ。文字なし」です。

4枚を並べて見て（2026年11月2日に見比べました）、気づいたことが3つあります。

  • 「和室」を描けたのはFLUXだけでした。手元の2モデルは、英語圏でよく見る机の写真のような構図に寄りました
  • 「文字なし」と書いても、文字のような模様が出ることがあります。掛け軸、カレンダー、レシートのように、本来文字がある物はとくに出やすいです
  • 手元の2モデルは、器の数を指定どおりにしません。「湯のみ1つ」のつもりが3〜4個になりました

どれも「記事の雰囲気に合う絵」としては十分です。一方で、図解のように中身が正確でないと困る絵には向いていません。

5. 記事用に29枚作って、使えたのは19枚

試した日のあと、実際の記事用には手元のPCの方法（Juggernaut-XL）を使っています。作った枚数と、使えた枚数を記録から数えました。

表2：記事用に生成した枚数と採用数（手元のPC・Juggernaut-XL）
時期生成採用没
2026年10月17日（既存記事4本の画像を差し替え）15枚8枚7枚
10月22日〜11月1日（新しい記事5本）13枚10枚3枚
11月2日（この記事の冒頭の画像）1枚1枚0枚
合計29枚19枚（66%）10枚

最初の日は半分近くが没でした。お題の書き方を直してからは、没が13枚中3枚に減っています。ただ、記事ごとに題材が違うので、お題の書き方だけが効いたとは言い切れません。採用した10枚のうち1枚は、画面の中に出た文字のような模様を消してから使っています。

没にした理由は、だいたい次の4つでした。

  1. 文字のような模様が出た。計器の目盛、カレンダー、レシートなど。お題から「カレンダー」を外し、避けたいものに「数字」を入れると減りました
  2. 物の形がおかしい。じょうろや水差しの注ぎ口が2本になる、など。1枚の中の物を減らすと当たりやすくなりました
  3. 図の意味が描けない。天秤、点線の矢印、つり革のような「関係」を表す絵は崩れます。数字や関係を見せたい図は、自分で図を書くことにしました
  4. イラストを頼んでも写真風になる。「フラットなベクター調」と書いても、置き物を上から撮った写真のようになりがちでした。この指定を強めると改善しました

時間は、ほかの重い処理と同時に動かした日は1枚50〜120秒に延びました（最初の1枚は286秒）。単独で動かせば、今日の冒頭の画像は33秒で出ています。

6. いま使っている順番

この結果から、記事の挿絵は次の順番で作っています。

  1. 手元のPC（SDXL Lightning）。回数を気にせず何枚でも作り直せるので、雰囲気の挿絵とアイキャッチはまずここ
  2. ChatGPTかGeminiの無料Web版を、自分の手で。和室のように「その場所らしさ」が要る絵、手元で何度やってもうまくいかない絵だけ
  3. Hugging Faceの公開デモ。速いが、無料枠が1日数枚で尽きるので、試しに使う程度
  4. 自分で図を書く。数字・矢印・文字が入る図は最初からこれ。このサイトのグラフは全部この方法です

手元で動かす方法は、最初の準備（ソフトとモデルのダウンロード）に手間がかかります。それでも、毎日使うなら、1日の枠を気にしなくていいことの方が大きいと感じています。準備に必要な容量や手順は、使うPCによって違うので、ここでは書いていません。

まとめ

  • 2026年10月17日に無料のAI画像生成10手段を同じお題で試し、画像が出たのは5手段。APIの4手段は、無料枠0か残高0で出ませんでした
  • 手元のPCで動かす方法は約32秒で1枚・上限なし・0円。お題への忠実さは、公開デモのFLUXの方が上でした
  • 記事用に作った29枚のうち19枚を使いました。没の理由は、文字のような模様・物の形・図の意味・写真風の4つでした
